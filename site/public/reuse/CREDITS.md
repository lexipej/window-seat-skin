# Reuse preview backdrops

The preview window in the Reuse section shows the skin over a still that matches the chosen marker.

| Marker | Backdrop | Source | Licence |
|---|---|---|---|
| station | A frame of the playing ISS pass, served by Mux as a thumbnail (`image.mux.com/<playbackId>/thumbnail.webp`) | NASA Johnson Space Center, Crew Earth Observations (the clips credited on the page) | Public domain (US government work) |
| plane, ship, car, helicopter, train | `plane.jpg`, `ship.jpg`, `car.jpg`, `helicopter.jpg`, `train.jpg` in this folder | Generated by the site author with CapCut's image generator | Supplied by the site author for this project |
| dot | Neutral CSS gradient (`.backdrop[data-scene="dot"]` in `site-alt/src/styles.css`) | Window Seat | Apache 2.0, with the code |

The images are bundled through `import.meta.glob` in `site-alt/src/customizer.ts`; adding or removing a file here changes which markers show a photo.
